# Results

Generated by analysis/make_table.py from results/raw. Latency is mean &plusmn; standard deviation in ms over the timed iterations (n is in summary.csv). 
Stack is the peak measured by stack painting, in KiB, max over the three operations. Heap is the peak of live allocations above the starting point, max over operations. 
Flash is code plus read-only data of the objects that belong to the algorithm, including the PQClean hash code (SHAKE or SHA-2) it needs; the per-component split is at the bottom. Sizes are in bytes.
